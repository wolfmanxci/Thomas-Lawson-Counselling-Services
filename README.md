# Thomas-Lawson Counselling Services — Website Legal & Compliance Documents

This repository hosts the public-facing legal, compliance, and privacy documentation for **Thomas-Lawson Counselling Services** (https://thomaslawsoncounselling.co.uk).

## Repository Contents

*   `index.html` — The main hub page providing a clean, accessible directory to all legal policies.
*   `privacy-policy.html` — The comprehensive UK GDPR-aligned privacy document containing updated clinical storage declarations, special category data handlers, and professional retention policies.
*   `cookie-policy.html` — Transparent guidelines detailing website cookies and user opt-out management.
*   `terms-of-use.html` — The governing terms, intellectual property, and liability guidelines for the website.
*   `logo.png` — The core brand asset used across all documentation headers.
